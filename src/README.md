# Java OOP Project 

A simple Java project created to practice Object-Oriented Programming concepts.

## Concepts

- Classes and Objects
- Encapsulation 
- Inheritance
- Polymorphism
- Method Overriding

## Project Overview

The project simulates a simple audio platform with different types of content, such as 
song and podcasts.

Both Song and Podcast inherit common attributes and behaviours from the Audio class while
implementing their own rating rules. 

A recommendation service evaluates different audio types based on their ratings.

## Purpose 

This project was developed as part of my Java Studies to strengthen
my understanding of Object-Oriented Programming and clean code organization.
